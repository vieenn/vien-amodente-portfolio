Automatic Timetable Generator

An academic web-based timetable generation system developed as a team project. The application uses a Genetic Algorithm to automatically generate conflict-free class schedules based on predefined scheduling constraints, reducing the time and effort required for manual timetable creation.

The Genetic Algorithm was used to optimize timetable generation by minimizing scheduling conflicts while satisfying predefined constraints such as instructor availability, room assignments, and class schedules.
