JARVIS – Local AI Personal Assistant

A Python-based voice-controlled personal assistant currently in development. JARVIS runs in the background without requiring a traditional graphical interface, allowing natural voice interaction with the computer. The system combines local voice processing, AI-powered conversation, persistent user memory, and Windows desktop automation. Current capabilities include wake-word activation, speech recognition, local text-to-speech, AI conversations, application control, Spotify playback, system monitoring, screenshot capture, Windows locking, and Google Maps search.



Tech Stack

Python openWakeWord Piper OpenRouter OpenAi Python SDK PyAutoGUI Windows APIs
