JARVIS – Local AI Personal Assistant

A locally running voice-controlled personal assistant currently in development using Python. JARVIS runs in the background without a visible user interface, allowing natural voice interaction with the computer. Current features include voice commands, application launching, music playback through Spotify and YouTube, and computer automation.



Tech Stack

Python openWakeWord Piper Voice-Controlled Computer Automation

My Role

  • Developed a locally running voice-controlled personal assistant using Python.
  • Implemented wake-word detection for hands-free activation.
  • Integrated local text-to-speech for voice responses.
  • Implemented voice commands for launching desktop applications.
  • Added voice-controlled music playback through Spotify and YouTube.
  • Developed computer automation features triggered through voice commands.
  • Designed the system to operate locally without relying on cloud-based AI services.
